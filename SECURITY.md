# Security policy

[Español](SECURITY.es.md)

## Report a problem privately

Use GitHub's private vulnerability reporting on this repository. Please keep containment escapes, harmful scenarios and exposed secrets out of public issues. Use the same channel to report abuse.

## In scope

- A way out of the arena.
- A catalog scenario that causes real harm or targets a real system.
- A scenario that could harm someone who only opened the repository with an agent.
- Any exposed credential or personal data.

## Potentially harmful content

This project is designed to store descriptions of prompt injection attacks for defensive research. Today it stores none. Scenarios must stay limited to generated canaries and simulated destinations, and real exploits or malware are not accepted.

## Findings about other products

If BSA finds a new weakness in a product, it is reported privately to the vendor first, and the result stays unpublished until the vendor has had reasonable time to respond.
