# Política de seguridad

[English](SECURITY.md)

## Cómo reportar un problema en privado

Usa el reporte privado de vulnerabilidades de GitHub en este repositorio. Por favor, no abras issues públicos sobre fugas de la arena, escenarios dañinos o secretos expuestos. Usa el mismo canal para reportar abusos.

## Alcance

- Una forma de salir de la arena.
- Un escenario del catálogo que cause daño real o apunte a un sistema real.
- Un escenario que pueda dañar a alguien que solo abrió el repositorio con un agente.
- Cualquier credencial o dato personal expuesto.

## Contenido potencialmente dañino

Este proyecto está pensado para guardar descripciones de ataques de inyección de prompts con fines de investigación defensiva. Hoy no guarda ninguna. Los escenarios deben limitarse a canarios generados y destinos simulados, y no se aceptan exploits reales ni malware.

## Hallazgos sobre otros productos

Si BSA encuentra una debilidad nueva en un producto, primero se reporta en privado al proveedor, y el resultado no se publica hasta que el proveedor haya tenido un tiempo razonable para responder.
